Overview / Objective

你这次要真正回答的，不是“怎么扫”，而是“扫出来的到底是什么”

在控制里，“扫频”本质上是在某个工作点附近，向系统注入正弦信号，然后观察输出如何随频率变化。 因此你最终测到的，不是某个神秘指标，而是某条 输入 → 输出 动态关系在频域里的样子。

$$G(j\omega)=\frac{Y(j\omega)}{U(j\omega)}$$

问题在于：电机控制是多闭环系统。你把信号注入在哪一层、输出看哪一个量、机械端是否允许转动、 电流环是否足够快，这些都会改变你“扫到”的对象。

本作业的最低目标 不要只给“仿真截图”。你必须明确写出：这次扫频的输入是什么、输出是什么、中间经过哪些环节、哪一部分是你想测的、哪一部分是你不想混进去的。

层次 1：看现象

先让脚本跑起来，观察速度、i_q、i_d、负载转矩、命令值与反馈值的波形随频率的变化。

层次 2：解释路径

说明这条扫频是在测 tracking、disturbance rejection，还是混合了电气与机械动态。

层次 3：会调参数

通过 tuner.py 改带宽，再回来看扫频结果为什么变化，尤其关注电流环对速度环的支撑作用。

Hints / Physics + Code

下面这些提示足够把你推到正确方向，但不会替你做完作业

提示 1：扫频测的是“某条通道”的频率响应

如果你扫的是速度参考，输出看速度，那么更接近在测 速度闭环 tracking； 如果你扫的是负载转矩，输出看速度，那么更接近在测 速度环的抗扰能力； 如果你扫的是电流参考，输出看电流，那么目标是测 电流环，但前提是别把机械动态混进去。

提示 2：扫电流环时，先想清楚你到底要不要让机械系统参与

扫 d 轴电流

对表贴 PMSM 或零弱磁工作点而言，纯扫 d 轴通常不直接产生产生平均电磁转矩。 如果转子不动，就没有与转速相关的动生反电势项干扰，是观察电流环的较“干净”方式。

扫 q 轴电流

i_q 直接决定电磁转矩。若电机可以自由转动，那么你一边在扫电流环，一边也在激发机械方程。 此时测到的未必还是“纯电流环”，而是电流环与机械环耦合后的结果。

所以你要自己判断 如果你的目标是尽量测“纯电流环”，你更希望 转速不变（最好近似恒定，甚至为零）， 这样可以尽量消掉机械动态和速度相关反电势的影响。你必须用自己的实验去证明这件事。

提示 3：为什么速度参考扫频时，i_q 幅值往往越扫越大？

$$J\frac{d\omega_m}{dt}=T_e-T_L,\qquad T_e=\frac{3}{2}n_{pp}K_A i_q$$
$$\omega_m^\ast(t)=A\sin(2\pi f t)\;\Rightarrow\; \frac{d\omega_m^\ast}{dt}=2\pi f A\cos(2\pi f t)$$

也就是说，在速度振幅 A 固定时，频率 f 越高，所需加速度幅值越大； 为了实现更大的加速度，就需要更大的电磁转矩，而转矩又需要更大的 i_q。 这就是你报告里应该出现的主线之一。

提示 4：速度参考扫频与负载转矩扫频，既相关又不同

它们都经过 同一个闭环系统，所以常常会共享相同或相近的闭环极点结构； 但二者的注入点不同：一个是从参考端进入，一个是从扰动端进入，因此分子、符号、低频意义都不一样。

$$\frac{\omega_m}{\omega_m^\ast}\sim \frac{C_v G_i G_m}{1+C_v G_i G_m}, \qquad \frac{\omega_m}{T_L}\sim -\frac{G_d}{1+C_v G_i G_m}$$

你不必完全照抄这个符号写法，但报告里至少要表达出：二者共享闭环分母，却不是同一条传递函数。

提示 5：电流环是速度环眼中的“转矩执行器”

从速度环角度看，速度 PI 并不直接产生转矩，它先产生 i_q^*，再由电流环把 i_q^* 尽量快地变成真实 i_q。 因此电流环越慢，速度环看到的“执行器”越迟钝，抗负载扰动的能力越差，相位滞后也更大。

提示 6：带宽在代码里不是抽象概念，它被写成了明确公式

$$K_{p,i}=2\pi\,L\cdot \text{BW}_{c},\qquad K_{i,i}=\frac{R}{L}$$
$$K_{i,\omega}=\frac{\omega_{ci}}{\delta^2},\qquad K_{p,\omega}=\frac{J_s/n_{pp}}{1.5\,n_{pp}\,K_A}\,\delta\,K_{i,\omega}$$

这些关系就在 simulation/tuner.py 中。请你把公式、代码变量名和实验结果连起来： 哪个参数主要影响电流环？哪个参数控制速度环目标带宽？delta 为什么会影响速度环设计？

提示 7：不要忽略限幅与工作点

  • 若频率太高，可能不是“环路小信号能力不够”，而是电压或电流限幅先到了。
  • 若你扫的是 q 轴电流且允许转速变化，那么工作点会漂移，系统不再是你以为的那个线性化点。
  • 若每个频率停留太短，幅值与相位提取可能不可靠。
  • 若你开启或关闭解耦电压补偿，电流环结果也会发生变化，这一点值得加分讨论。
